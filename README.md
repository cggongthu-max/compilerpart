# Compilerpart

Incremental experiments in building a compiler targeting the **MMIX** architecture
(Knuth's 64-bit RISC machine). Each sub-project compiles a progressively larger
subset of C into MMIX assembly, verified on the MMIX simulator.

## Part 1 — Simple Arithmetic (`simple-arith.c`)

**Goal:** Compile a single arithmetic expression (integers 0–9, operators `+ - * /`,
parentheses) into MMIX instructions.

**Input:**
```
3*(5-2)
```

**Generated MMIX (`simple-arith-out/simple-arith-out0.mms`):**
```
        LOC  #100
Main    IS   @
        LOC  Main
        SETL $1,3
        SETL $2,5
        SETL $3,2
        SUB  $2,$2,$3
        MUL  $1,$1,$2
        TRAP 0,Halt,0
```

**Verification (mmix simulator trace):**
```
$ mmix -t1 simple-arith-out0
1. 0000000000000100: e3010003 (SETL) $1=l[1] = #3
1. 0000000000000104: e3020005 (SETL) rL=3, $2=l[2] = #5
1. 0000000000000108: e3030002 (SETL) rL=4, $3=l[3] = #2
1. 000000000000010c: 24020203 (SUB)  $2=l[2] = 5 - 2 = 3
1. 0000000000000110: 18010102 (MUL)  $1=l[1] = 3 * 3 = 9
1. 0000000000000114: 00000000 (TRAP) Halt(0)
```

`$1 = 9` ✓ — matches `3*(5-2) = 9`.

## Part 2 — JCC0 (`jcc0/`)

**Goal:** Compile a small subset of C to MMIX. Supported features:

| Feature | Example |
|---------|---------|
| `int` variable declarations | `int s; int i;` |
| Assignment | `s = 0;` |
| Arithmetic expressions | `s + i`, `i + 1` |
| Comparison operators | `<=`, `>=`, `<`, `>`, `==`, `!=` |
| `while` loop | `while (i <= 100) { ... }` |
| Block statements | `{ ... }` |

**Input:**
```c
int s; int i;
s = 0; i = 1;
while (i <= 100) {
    s = s + i;
    i = i + 1;
}
```

**Build & Run:**
```bash
cd jcc0
make
./JCC02M              # uses built-in test case
./JCC02M input.c      # or compile from file
```

**Generated MMIX (`i100-sum-out/i100-sum-out.mms`):**
```
% Generated by JCC02M
        LOC  Data_Segment
        GREG @
        LOC  #100
Main    IS   @
        LOC  Main

% decl: int s -> $2
% decl: int i -> $3
        SET $2,0
        SET $3,1

L0      SET $200,100
        CMP $201,$3,$200
        BP  $201,L1
        ADD $202,$2,$3
        SET $2,$202
        SET $203,1
        ADD $204,$3,$203
        SET $3,$204
        JMP L0

L1      TRAP 0,Halt,0
```

**Verification:** Run under the MMIX simulator and inspect `$2` after halt.
Expected value: **5050** (= 1+2+...+100).

```bash
mmix -t1 i100-sum-out
# ... (trace omitted for brevity) ...
# Confirm $2 = #13BA (= 5050 decimal) at halt
```

## Testing Methodology

Since this compiler targets a bare-metal subset (no `printf`, no stdlib),
correctness is verified via the **MMIX simulator**:

1. **Assemble** the generated `.mms` file with `mmixal`.
2. **Run** with `mmix -t1` (trace mode) to observe every instruction.
3. **Inspect registers** at halt to confirm the expected result.

| Part | Expected Register | Expected Value | Meaning |
|------|-------------------|----------------|---------|
| simple-arith | `$1` | `9` | `3*(5-2)` |
| jcc0 (i100-sum) | `$2` | `5050` | `1+2+...+100` |

Tools used: [MMIX tools by Donald Knuth](https://mmix.cs.hm.edu/)
(`mmixal` assembler + `mmix` simulator).
